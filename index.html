    LES RÈGLES DU JEU

    Un code. À vous de le trouver.

    1. Découvrez les quatre couleurs du code, dans le bon ordre. Une couleur peut se répéter.
    2. Choisissez une position, puis une couleur parmi les six proposées. Vous pouvez tout modifier avant de valider.
    3. Après chaque proposition, consultez les deux nombres : couleurs bien placées et couleurs présentes mais mal placées. Chaque occurrence compte une seule fois.
    4. Vous avez dix essais. Quatre couleurs bien placées donnent la victoire, même au dernier essai.
    5. Une proposition incomplète ou non autorisée ne consomme aucun essai. Après la fin, lancez une nouvelle partie pour rejouer.
